# AI Ticketing System

AI Ticketing System è un'applicazione web sviluppata con React, TypeScript e Node.js che permette la gestione di ticket di supporto tecnico.

## Obiettivi del progetto

Questo progetto nasce con lo scopo di approfondire lo sviluppo frontend moderno con React e TypeScript, integrando successivamente funzionalità di Intelligenza Artificiale e automazione dei processi.

## Funzionalità previste

* Creazione di ticket di assistenza
* Visualizzazione elenco ticket
* Dettaglio ticket
* Aggiornamento dello stato dei ticket
* Sistema di autenticazione utenti
* Dashboard amministrativa
* API REST backend
* Integrazione con modelli AI per classificazione automatica dei ticket
* Automazioni tramite n8n
* Notifiche email e Telegram
